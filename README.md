# MTU_IEEE_XYZprinting
The slicer configuration files here use OrcaSlicer [www.orcaslicer.com](https://www.orcaslicer.com) as the slicer of choice for slicing files for the printer\
\
Importing the orca_printer file to import the printer set up, filament presets, and a base printer operation configuration.\
\
Use the sd card on the back of the 3d printer to upload files to the printer.
>Note: the file may not show up because of the name to you may need to edit the name of the file for it to show up.
>Problem letters may be: V

Check other documents for other possibly needed information.

## Slicing
Stuff to watch for when slicing a 3d print
- If there is large over hangs turn on supports
- Make sure the proper filament type is selected pla and abs need two different temps to print properly
- When multi color printing watch that the locations of the prime tower is in the printable area
- After clicking slice check that all of the print is in the printable area

## Printing
Stuff to know for printing
- Glue is needed for the print to stick to the bed
- filament spools should be monitored to make sure that they are spinning since they are just sitting on the back of the printer
- monitor that the print is printing how it is sliced otherwise you may want to cancel the print
